Reiki healing

Reiki er en japansk energibehandling, som arbejder med at genoprette balance og harmoni i kroppen. Hvis vi udsættes for stress eller anden form for overbelastning, kan vores indre energi komme ud af balance, hvilket kan vise sig fysisk. Når den universelle livsenergi, eller ki, som Reiki bygger på, tilføres kroppen, vil den være med til at genoprette denne balance.

Med min spirituelle indsigt kan jeg desuden fornemme hele vores energifelt og de forskellige energetiske områder i kroppen, som kalder på særlig opmærksomhed. Derfor vil en Reiki session hos mig også bære præg af arbejdet med eventuelle blokeringer eller steder, hvor energien flyder langsomt.
